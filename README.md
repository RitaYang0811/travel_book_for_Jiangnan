# travelBook

幫長輩跟團出遊時做的手機旅遊書。

可以加到手機主畫面，**沒有網路也能看**，專為長輩設計：字大、對比高、操作簡單。

## 功能

| 分頁    | 內容                                                                                                                   |
| ------- | ---------------------------------------------------------------------------------------------------------------------- |
| 🏠 總覽 | 出發倒數、航班（待確認，可修改）、五天行程一覽、領隊與導遊聯絡方式                                                     |
| 🗺️ 行程 | 每日路線與車程、景點介紹（點一下展開）、早午晚餐、住宿候選飯店、溫馨提醒；可以自己填房號、叫醒時間、集合時間地點、筆記 |
| 🧳 行李 | 先生、女士各一份清單，依 10 月底江南天氣準備；可勾選、自己新增，向左滑刪除                                             |
| 💰 記帳 | 人民幣 ⇄ 台幣匯率換算（連線時自動更新）；依天數記錄花費、自動加總，向左滑刪除                                          |
| 📋 須知 | 行程注意事項、當地實用資訊、緊急聯絡電話、健康小卡、傳資料給另一支手機                                                 |

右上角的「小／中／大」可以切換字體大小。

## 在手機上使用

1. 用手機打開網站網址（第一次開啟需要網路）
2. 加到主畫面
   - **iPhone**：Safari → 分享 → 「加入主畫面」
   - **Android**：Chrome → 選單 → 「加到主畫面」
3. 之後**一律從主畫面的圖示打開**，沒有網路也能使用

> iPhone 在 Safari 裡填的資料和主畫面 App 裡的資料是分開存的，請都在主畫面 App 裡填寫。

### 讓兩支手機資料一樣

資料只存在各自的手機裡，不會上傳。建議由一個人負責填寫：

1. 在填好資料的手機：「須知」→「複製我的資料」→ 用 LINE 傳給對方
2. 在另一支手機：把文字貼到框框 →「匯入這份資料」

匯入會**整份取代**這支手機原本的內容，不會合併。

## 開發

純 HTML / CSS / JavaScript，不需要安裝或建置。

```bash
python3 -m http.server 8000
# 打開 http://localhost:8000
```

| 檔案                           | 用途                                 |
| ------------------------------ | ------------------------------------ |
| `index.html`                   | 整個網站（畫面、樣式、程式都在這裡） |
| `sw.js`                        | Service Worker，負責離線快取         |
| `manifest.json`                | 加到主畫面時的名稱、圖示、顏色       |
| `icon-180.png`、`icon-512.png` | App 圖示                             |

### 修改內容

- **行程**：`index.html` 裡的 `DAYS`（景點、餐食、飯店、提醒）
- **行李清單**：`index.html` 裡的 `PACK`
- **記帳分類**：`index.html` 裡的 `EXP_CATS`

### 發布新版

修改後**一定要把 `sw.js` 的版本號 +1**，例如 `jiangnan-v6` → `jiangnan-v7`，否則手機會一直讀舊的快取。

部署到任何靜態網站空間都可以（例如 GitHub Pages：Settings → Pages → 選 `main` 分支）。

## 資料來源

- 行程內容：[東南旅遊行程頁](https://tour.settour.com.tw/product/GFG0000000204/HDNBP5261028A)。實際航班、飯店與行程順序以行前說明會資料為準。
- 匯率：[ExchangeRate-API](https://www.exchangerate-api.com/)（備援：[fawazahmed0/currency-api](https://github.com/fawazahmed0/exchange-api)），為每日更新的市場中間價，和銀行實際換匯價格會有些差異。
